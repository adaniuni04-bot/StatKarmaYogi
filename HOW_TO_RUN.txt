============================================================
 STATKARMAYOGI PLATFORM - HOW TO RUN FROM ZIP
============================================================

PREREQUISITES:
1. Python 3.10+ installed and added to PATH
2. Node.js 18+ installed (https://nodejs.org)
3. (No local GPU or Ollama required!)
   The platform is powered by Groq Cloud Console for ultra-fast
   cloud AI inference with Qwen models.

------------------------------------------------------------
AI CLOUD SETUP (GROQ CONSOLE / QWEN 3.8):
------------------------------------------------------------
1. Get your free API key at: https://console.groq.com/keys
2. Open the ".env" file in a text editor (Notepad or VS Code).
3. Find the line:
      GROQ_API_KEY=
   and paste your key, for example:
      GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxxxxx
4. Save the file. That's it! All AI career tutor, diagnostic
   assessments, and skill evaluations will immediately run via Groq.

* NOTE: If you haven't added an API key yet, the platform will
  still run safely using built-in deterministic evaluation!

------------------------------------------------------------
OPTION A: 1-CLICK LAUNCH (WINDOWS)
------------------------------------------------------------
1. Extract this ZIP folder to any location on your PC.
2. If running for the very first time:
   Double-click "install_dependencies.bat"
3. To start both Backend and Frontend together:
   Double-click "start_all.bat"
4. Open your browser at:
   http://localhost:3000

------------------------------------------------------------
OPTION B: MANUAL TERMINAL LAUNCH
------------------------------------------------------------

Step 1: Start Backend (Terminal 1)
   cd backend
   pip install -r requirements.txt   (first time only)
   python -m uvicorn app.main:app --host 0.0.0.0 --port 8000

Step 2: Start Frontend (Terminal 2)
   cd frontend
   npm install                       (first time only)
   npm run dev

Step 3: Open in Browser
   - Web Application: http://localhost:3000
   - Interactive API Docs: http://localhost:8000/docs
